iCloud

Delte checkliste (Påmindelser)

Ikke konfigureret

iCloud-påmindelser over IMAP er en anden database end den i Påmindelser-appen. Vælg derfor Mac mini-bridge, hvis du vil se præcis dine egne påmindelser.

Mac mini-bridge

Find IP-adressen på Mac mini'en under Systemindstillinger → Wi-Fi → Detaljer. FamilyBridge lytter på port 8787.

Find tokenet på Mac mini'en med: /Applications/FamilyBridge.app/Contents/MacOS/FamilyBridge --token

iCloud CalDAV

Brug dit Apple-id og et app-specifikt adgangskode (appleid.apple.com → Adgangskode → App-specifikke adgangskoder).

Listen, du vælger her, bliver tovejssynkroniseret med checklisten på dashboardet.

iCloud

Delte note (Note på iPhone)

Ikke konfigureret

iCloud Notes kan ikke hentes via IMAP – Notes-mappen er altid tom. Brug derfor Mac mini-bridge, som læser den ægte Notes-database via Notes.app.

iCloud IMAP

Bemærk: Kun en note med nøjagtig samme titel i Notes-appen opdateres. Noten læses og skrives via FamilyBridge på Mac mini'en.
